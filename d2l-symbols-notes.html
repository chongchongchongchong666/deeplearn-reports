3.2 点积 ⟨x, y⟩：相似度的度量

# 坐标定义：对应分量相乘再求和
⟨x, y⟩ = x₁y₁ + x₂y₂ + … + xₙyₙ = Σᵢ xᵢyᵢ

例：x = [1,2,3], y = [4,5,6]
⟨x,y⟩ = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32

# 几何意义
⟨x,y⟩ = ‖x‖·‖y‖·cosθ
θ=0° 同向 → cos=1 点积最大（最相似）
θ=90° 垂直 → cos=0 点积=0（无关）
余弦相似度 = ⟨x,y⟩ / (‖x‖·‖y‖)  ∈ [-1, 1]

# 项目04：特征 L2 归一化后 ‖x‖=1 → 余弦相似度 = 点积
# → 10000 张图检索只需一次矩阵乘法
图 6 · 点积的几何：余弦相似度"只看方向、不看长短"，归一化后 ∈ [−1,1]

3.3 Lp 范数：p 决定距离的形状

‖x‖ₚ = ( Σᵢ |xᵢ|ᵖ )^(1/p)

p=1: ‖x‖₁ = |x₁|+|x₂|+…      曼哈顿距离（菱形）→ 稀疏解 → L1 正则
p=2: ‖x‖₂ = √(x₁²+x₂²+…)     欧氏距离（圆形）→ 默认的 ‖·‖
图 7 · L1 菱形 vs L2 圆形：棱角 + 损失等高线 = 稀疏解
🔑 稀疏推导核心：损失等高线（椭圆）缩小后最先撞上菱形的角，而菱形的角正好落在坐标轴上 → 该维权重精确为 0。L2 是光滑的圆，没有角，权重只会变小不会归零。L1 在 0 点的"尖角"（梯度恒为 ±1）就是拖着权重往 0 走的恒定推力。
L1 正则L2 正则（岭回归）
形状菱形（有棱角）圆形（光滑）
结果稀疏：部分权重 = 0平滑变小但不为 0
用途特征选择、压缩感知防过拟合（PyTorch 的 weight_decay）
总损失 = 数据损失 + λ·‖w‖     # ‖w‖ 大 → 罚分高 → 不敢大权重拟合噪声
λ=0 不惩罚；λ 太大 → 欠拟合。深度学习默认用 L2（weight_decay=1e-4）

四、微积分 d ∂ ∇ ∫

四个符号是反向传播的全部数学工具：导数=切线斜率、偏导=单方向变化率、梯度=全方向最陡、积分=曲线下面积。

图 8 · 微积分四符号：导数 · 偏导 · 梯度 · 积分

推导 ① 导数 → 偏导 → 梯度（三步走）

# 第1步 导数（一元）：割线取极限变切线
dy/dx = lim[h→0] [f(x+h) − f(x)] / h
f(x)=x² → f′(x) = lim [(x+h)²−x²]/h = lim (2xh+h²)/h = 2x

# 第2步 偏导（多元）：只让一个变量动，其他按住不动
f(x,y) = x² + 2y²
∂f/∂x = 2x    # y 当常数（2y² 求导变 0）
∂f/∂y = 4y    # x 当常数

# 第3步 梯度：所有偏导拼成向量，指向"上坡最陡"
∇f = [2x, 4y]，在 (1,2) 处 = [2, 8]
梯度下降走【负】方向：w ← w − η·∇L   # 下坡最陡，这就是训练的全部几何
图 9 · 梯度垂直等高线指向"最陡上坡"；训练永远沿 −∇L 反方向跨向谷底

推导 ② 定积分（黎曼和取极限）

∫ₐᵇ f(x)dx = lim[n→∞] Σᵢ f(xᵢ)·Δx     # [a,b] 切成 n 条窄矩形，Δx→0
例：∫₀¹ x² dx = [x³/3]₀¹ = 1/3   # 抛物线下面积 = 0.333…
🔗 关系链：导数（一元）→ 偏导（单方向）→ 梯度（全方向打包）→ 反向传播主角；积分是"由变化率还原总量"的逆运算。口诀：前向算损失 L，反向求 ∂L/∂w，参数沿 −∇ 方向更新。
图 10 · 计算图上的链式法则：前向算 loss，反向把偏导一段段乘回去 —— "反向传播"名字的由来

五、概率与信息论 E Var H DKL

生成模型与交叉熵损失的数学底座。五大块：期望方差（集中与离散）、条件概率、熵与自信息（不确定性）、KL 散度（分布差异）、协方差与相关（两两关系）。

5.0 先认脸：五个基础符号

符号含义一句话理解
P(·)概率分布给每个可能结果发一个 [0,1] 的概率，全部加起来 = 1
z ∼ P服从分布 P随机变量 z 是按分布 P 抽出来的（掷骰子 z ∼ 均匀分布）
p(x)概率密度 / 概率值连续变量看密度（曲线下的面积才是概率），离散变量直接是概率
X ⊥ Y独立知道 Y 对猜 X 毫无帮助：P(X,Y) = P(X)·P(Y)
X ⊥ Y | Z给定 Z 条件独立固定 Z 之后，Y 对 X 就不再提供新信息
图 11 · 概率五符号案例：抽签（z∼P）· 密度曲线（p(x)）· 两对"断开"的关系（⊥ 与 ⊥|Z）

5.1 期望与方差：重心与偏离

图 12 · 期望是重心，方差用平方惩罚偏离
# 方差推导（一气呵成）
Var(X) = E[(X−μ)²]           # 定义
       = E[X²] − 2μ·E[X] + μ²  # 展开 + 期望线性
       = E[X²] − 2μ² + μ²      # E[X]=μ 代入
       = E[X²] − (E[X])²      ✅ 最终公式
标准差 σ = √Var(X)（回到原单位）
Cov(X,Y) = E[XY] − E[X]·E[Y]（协方差的计算形式）

5.2 自信息与熵：把"意外"量成 bit

图 13 · 分布越平 → 熵越大越难猜；越陡 → 熵越小越好猜
自信息：I(x) = −log p(x)   # 要几个二选一才能猜中
熵：    H(X) = E[I(x)] = −Σ p(x)·log p(x)   # 意外的加权平均
公平币 p=0.5 → H=1 bit（最不确定）；必然事件 p=1 → H=0（零信息）

# 派生链：交叉熵 → KL 散度
交叉熵 H(P,Q) = −Σ p·log q          # 用 Q 编码 P 的数据
D_KL(P‖Q) = H(P,Q) − H(P) = Σ p·log(p/q)   # 额外浪费

5.3 KL 散度：完整推导

图 14 · 条件概率（面积比）与 KL 散度（双分布对比）
# 第一步 两笔平均账
H(P)   = E_P[−log p] = −Σ p·log p       # 真实需要的 bit（熵）
H(P,Q) = E_P[−log q] = −Σ p·log q       # 用 Q 编码 P 的平均花费（交叉熵）

# 第二步 相减 = 额外浪费
D_KL(P‖Q) = H(P,Q) − H(P)
          = −Σ p·log q + Σ p·log p
          = Σ p·(log p − log q)
          = Σ p(x)·log( p(x)/q(x) )    ✅ 标准公式

# 数值验证：P=[0.5,0.5], Q=[0.1,0.9]（log₂）
H(P)=1 · H(P,Q)=1.736 → 浪费 = 0.736
直接算：0.5·log(0.5/0.1)+0.5·log(0.5/0.9) = 1.16−0.424 = 0.736 ✅ 一致

# 非负性（Jensen 不等式，log 凹函数）
D = −E_P[log(q/p)] ≤ −log(E_P[q/p]) = −log(Σq) = −log 1 = 0
等号 ⇔ P = Q

# 不对称：D(P‖Q)=0.736 ≠ D(Q‖P)=0.531（权重换 p→q）
# 分类 one-hot 时 H(P)=0 → KL = −Σ y·log ŷ = CrossEntropyLoss！
图 15 · Jensen 不等式的几何：弦永远压不过曲线 —— KL 散度"非负"的真正来源
🎯 一句话本质：训练神经网络 = 最小化 D_KL(真实 ‖ 模型)，让模型分布去贴合真实分布。GAN 判别器、知识蒸馏 KL(学生‖教师)、VAE 的 ELBO 全部源于这一个公式。

5.4 前向 KL vs 反向 KL：方向决定行为

图 16 · 同一个双峰 P，KL 方向不同 → Q 行为完全不同
前向 KL(P‖Q)反向 KL(Q‖P)
期望权重按 p 加权（P 有质量处都算账）按 q 加权（只算 Q 自己的地盘）
行为zero-avoiding：宁可糊不能漏zero-forcing：贴紧一个模式
别名均值覆盖 mean-seeking模式寻求 mode-seeking
应用最大似然训练（MLE）扩散模型 / DPO（防生成糊）

5.5 协方差与相关系数

图 17 · 散点的走向就是协方差的符号；ρ 归一化去掉量纲
Cov(X,Y) = E[(X−E[X])(Y−E[Y])] = E[XY] − E[X]·E[Y]
正偏离×正偏离 = + → 同向 Cov>0；正×负 = − → 反向 Cov<0

ρ = Cov / (σₓ·σᵧ)   # 量纲约掉，强制 [−1,+1] 才可比较
ρ=+1 完美正相关 · ρ=0 无线性关系（≠独立！）· ρ=−1 完美负相关
⚠️ 相关 ≠ 因果（冰淇淋销量与溺水率同涨，真凶是夏天）

六、复杂度 O(·)

大 O 描述算法增长趋势，忽略常数与低阶项，只保留最高阶。

图 18 · 复杂度增长曲线 —— n 一旦变大，O(n²) 立刻甩开所有曲线；这就是大模型避免显式矩阵求逆（O(n³)）的原因
O(1) 常数   → 数组按下标访问
O(log n)    → 二分查找
O(n) 线性   → 遍历数据集一个 epoch
O(n²) 平方  → 两两比较（相似度矩阵）
O(n³) 立方  → 矩阵求逆（大模型避免显式求逆的原因）

f(n) = 3n² + 100n + 5000 = O(n²)   # n=100万 时 3n²=3万亿 占绝对主导
